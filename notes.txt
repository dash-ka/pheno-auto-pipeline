One thing in what you ran: you activated pheno-auto right before vllm serve, but vLLM is installed in ~/vllm-env, not in pheno-auto. Run the server from the vLLM environment, in either of these two ways:

Directly (as you did before):

bash
tmux new -s vllm
source ~/vllm-env/bin/activate
CUDA_VISIBLE_DEVICES=0 vllm serve openai/gpt-oss-120b --served-model-name gpt-oss-120b \
    --max-model-len 32768 --gpu-memory-utilization 0.92 --port 8001 \
    --override-generation-config '{"max_new_tokens": 16384}'

Or through the package, from the pheno-auto environment:

pheno-auto vllm-serve --env ~/vllm-env --gpu 0 --port 8001 --max-model-len 32768 --answer-cap 16384

Wait until it says the server is running, then detach with Ctrl-b d.
Point the pipeline at port 8001. The pipeline expects 8000 by default, so in the other terminal:

source ~/envs/pheno-auto/bin/activate
pheno-auto run --sections ~/data/sections50 --hpo-dir ~/hpo --out ~/runs/test \
    --pmids ~/data/test2.txt --gold ~/data/sections50/gold50.tsv \
    --base-url http://localhost:8001/v1 --belink-gpu 1

To check the server first: curl http://localhost:8001/v1/models should list gpt-oss-120b.

These are the run50 server settings (32k context, answers capped at 16,384 tokens), which keeps new results comparable with run50. For long tables you could later try --max-model-len 65536 without the --override-generation-config line.

C. Terminal 2: the pipeline
bash
tmux new -s run
source ~/envs/pheno-auto/bin/activate
curl -s http://localhost:8001/v1/models | grep -o gpt-oss-120b && echo "server ok"

S=$HOME/data/sections50
H=$HOME/hpo
O=$HOME/runs/run50-rerun
URL=http://localhost:8001/v1
mkdir -p $O

# 1. text sections
pheno-auto extract-text --sections $S --hpo $H/hp.obo --out $O/text \
    --model gpt-oss-120b --base-url $URL --pmids $S/pmids50.txt --workers 4 --temperature 0 \
    2>&1 | tee $O/1_text.log

# 2. tables
pheno-auto extract-tables --sections $S --hpo $H/hp.obo --out $O/tables \
    --model gpt-oss-120b --base-url $URL --pmids $S/pmids50.txt --workers 4 --temperature 0 \
    --max-tokens 32768 2>&1 | tee $O/2_tables.log

# 3. text + tables
pheno-auto concat $O/text/predictions.tsv $O/tables/predictions.tsv $O/both/predictions.tsv \
    2>&1 | tee $O/3_concat.log

# 4. BeLink, on GPU 1
CUDA_VISIBLE_DEVICES=1 BELINK_INDEX=$H/index BELINK_LOG=$O/both/predictions_belink.candidates.jsonl \
pheno-auto relink --pred $O/both/predictions.tsv --mode all \
    --term-mention-kinds table,suppl_table --out $O/both/predictions_belink.tsv \
    2>&1 | tee $O/4_relink.log

# 5. one name per patient
pheno-auto merge --pred $O/both/predictions_belink.tsv --out $O/both/predictions_merged_llm.tsv \
    --model gpt-oss-120b --base-url $URL 2>&1 | tee $O/5_merge.log

# 6. review zip
pheno-auto review-zip --pred $O/both/predictions_merged_llm.tsv \
    --candidates $O/both/predictions_belink.candidates.jsonl \
    --gold $S/gold50.tsv --sections $S --out $O/review.zip 2>&1 | tee $O/6_review.log
